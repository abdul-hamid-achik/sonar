# AGENTS.md

The instructions for this repository live in [CLAUDE.md](CLAUDE.md). Read that
file; this one exists so agents that look for `AGENTS.md` by convention find
their way there.

Keeping the guidance in one file is deliberate. This file used to carry its own
copy, and it drifted: it described `docs/` as a deployable product website —
inherited from the `local-agent` upstream, which has one and sonar does not —
and called the repository a "private fork of sonar", a fork of itself left
behind by the rename. Both statements were wrong, and neither was caught,
because nothing compares two prose files.
