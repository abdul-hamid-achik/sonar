This file provides guidance to Claude Code (claude.ai/code) when working with
code in this repository.

The guidance itself lives in [AGENTS.md](AGENTS.md) — the vendor-neutral file
every coding agent looks for — and is imported below so Claude Code loads it
without a second read.

There is deliberately no second copy here. When this repository carried two
prose files, they drifted: one described a `docs/` product website that does
not exist here, and called sonar "a private fork of sonar" — a fork of itself,
left behind by a rename. Both were wrong for months, because nothing compares
two prose files. Edit `AGENTS.md`; this file only points at it.
